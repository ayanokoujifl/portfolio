# Luís Gustavo Leite — Engineering Portfolio & Resume

Bilingual (**EN / PT-BR**) software engineering portfolio built with **Next.js 15 App Router**, **TypeScript**, and **Tailwind CSS**.

## Highlights
- Unified `[lang]` i18n routing (`/en`, `/pt`, `/en/projects`, `/pt/projects`, `/en/aboutme`, `/pt/aboutme`) driven by `src/data/portfolio.ts`
- Interactive WebP 3D showcase previews (Blender + Astro case studies) & native Android UI screenshot galleries
- Direct PDF downloads in `public/cv/` (`CurriculoLuisGustavo.pdf`, `ResumeLuisGustavo.pdf`)
- Dynamic `sitemap.xml`, `robots.ts`, and localized OpenGraph/canonical metadata

## Commands
```bash
npm install
npm run dev
npm run build
```
